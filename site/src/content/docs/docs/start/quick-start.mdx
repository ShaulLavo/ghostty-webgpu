You will have a terminal that prints a greeting, lets you edit a line at a prompt, and echoes each line you submit. Start with a browser TypeScript project, such as Vite's vanilla TypeScript template.

## 1. Install

```sh
npm install ghostty-webgpu ghostty-webgpu-line-editor
```

These docs follow the repository API. npm's current release predates it; use the current source checkout until the publishing update lands. In Fregat, build `packages/hotkeys/packages/hotkeys` and `packages/ghostty-webgpu` first, then import the workspace package. [Use ghostty-webgpu in your own app](https://github.com/ShaulLavo/fregat/blob/main/packages/ghostty-webgpu/docs/use-in-your-app.md) shows how to link the built package and ship its `.wasm` files.

## If it doesn't work

### The terminal has no rows

Give the host a nonzero height before calling `open`. A flex child may also need `min-height: 0` so its parent controls the size.

### The browser cannot load wasm

Keep the package's asset files in your bundler output. Serve them over HTTP with `application/wasm`; check the network panel for failed requests. [Workers and assets](https://ghostty.shaulavo.dev/docs/guides/workers/) lists the packaged files.

### Typed keys do nothing

Focus the terminal after opening it. This example installs `attachTerminalHotkeys` from `ghostty-webgpu/hotkeys` for the Ghostty keymap. Paste uses the browser event. The line editor claims input only while a `read` is pending.
