By the end of this page you will have a mounted terminal that prints a greeting, edits lines locally at a `$ ` prompt, echoes submitted input, and disposes cleanly on teardown. Any TypeScript bundler that serves `.wasm` files (such as Vite) works.

## 1. Install

```sh
npm install ghostty-webgpu @ghostty-webgpu/line-editor @shaulavo/hotkeys
```

`@ghostty-webgpu/line-editor` provides local line editing when no PTY is attached. `@shaulavo/hotkeys` is an optional peer used by `ghostty-webgpu/hotkeys`. If you are linking directly from a source checkout or configuring custom asset paths, read [Use ghostty-webgpu in your own app](https://github.com/ShaulLavo/ghostty-webgpu/blob/main/docs/use-in-your-app.md).

## 2. Give the host element a size

Place a container with a concrete height in your HTML. `open()` measures it synchronously and sizes the initial grid before painting frame one.

```html title="index.html"
<div id="terminal" style="height: 20rem; width: 100%"></div>
```

## 3. Mount, edit, and echo

Save this module as `terminal.ts` and call `mountEcho(host)` from your app entry point. Keep the returned disposer and call it when unmounting the view.

<Code code={sample} lang='ts' title='terminal.ts' />

What each call does:

- `Terminal.create({ accessibility: {} })` fetches and compiles `ghostty-vt.wasm` and `bridge.wasm`, creates the native session, and enables the accessible text mirror.
- `attachTerminalHotkeys(terminal)` binds the Ghostty shortcut table before the terminal opens.
- `terminal.use(readline())` installs the line-editor extension so Enter, Backspace, arrow keys, history, and Ctrl+C work without a remote shell.
- `await terminal.open(host)` mounts the DOM elements, fits the grid to `host`, starts Canvas-first rendering, and begins GPU warm-up in the background.
- `editor.read({ prompt: '$ ' })` resolves on each submitted line, and `editor.print()` writes output above the active prompt without corrupting it.

## Troubleshooting

### The terminal opens with default 80x24 dimensions

`open()` fits synchronously only when `host` has nonzero width and height. Give the container an explicit height before calling `open()`, and add `min-height: 0` on flex children so the parent constrains them. When a zero-sized host later gains dimensions, `ResizeObserver` fits it automatically.

### WebAssembly files fail to load

Confirm that `ghostty-vt.wasm`, `bridge.wasm`, `canvas-compose.wasm`, and `canvas-compose-scalar.wasm` are emitted by your bundler and served with `Content-Type: application/wasm`. You can pass explicit URLs through `runtime: { kind: 'owned', options: { wasm, bridge } }` and `compositorAsset`. See [Run in a worker](https://ghostty.shaulavo.dev/docs/guides/workers/) for worker asset URLs.

### Typing produces no characters

Call `terminal.focus()` after `open()` (or click the terminal). The line editor only claims keyboard input while an `editor.read()` call is pending.
