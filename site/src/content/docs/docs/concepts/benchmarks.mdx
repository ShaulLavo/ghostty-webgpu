The [benchmark report](https://github.com/ShaulLavo/fregat/blob/main/ghostty-webgpu/docs/benchmarks.md) owns the numbers, machine details, package versions, dates, method and reproduction commands. Use it when choosing a terminal for your workload.

This page links the report so updates to the benchmark work arrive in one place. It includes results and qualification limits. Compare the same renderer class and history policy, and keep parsing, streaming output, Unicode, scrolling and input latency separate.

For integration choices, read [renderers and fallbacks](https://shaullavo.github.io/ghostty-webgpu/docs/guides/renderers/). For the model behind frame work, read [damage tracking](https://shaullavo.github.io/ghostty-webgpu/docs/concepts/damage-tracking/).
