The terminal below prints a greeting and echoes each line you submit at its prompt. Click it, type a line and press Enter. Its source is the checked `mountEcho` module from [the quick start](https://ghostty.shaulavo.dev/docs/start/quick-start/).

import EchoTerminal from '../../../../components/EchoTerminal.astro'
import { Code } from '@astrojs/starlight/components'
import sample from '../../../../examples/quick-start.ts?raw'

<EchoTerminal />

<Code code={sample} lang='ts' title='quick-start.ts' />

[Connect a PTY](https://ghostty.shaulavo.dev/docs/guides/pty/) to replace the local line editor with a shell.
