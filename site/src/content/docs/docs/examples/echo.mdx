Click the terminal below, type a command or line of text, and press Enter. Arrow keys navigate line history, Backspace edits in place, and Ctrl+C cancels the current line. This widget mounts the exact `mountEcho` module checked by CI and introduced in [First terminal](https://ghostty.shaulavo.dev/docs/start/quick-start/).

import EchoTerminal from '../../../../components/EchoTerminal.astro'
import { Code } from '@astrojs/starlight/components'
import sample from '../../../../examples/quick-start.ts?raw'

<EchoTerminal />

<Code code={sample} lang='ts' title='quick-start.ts' />

To swap the local line editor for Bash over a WebSocket, follow [A real shell in the browser](https://ghostty.shaulavo.dev/docs/start/real-shell/) or [Connect to a PTY](https://ghostty.shaulavo.dev/docs/guides/pty/).
