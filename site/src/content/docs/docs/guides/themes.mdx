`ghostty-webgpu` represents colors as explicit `{ r, g, b }` integer objects and passes them directly to `libghostty-vt` and the renderers. That avoids CSS color parsing on the frame path and keeps palette lookups identical across WebGPU, WebGL2, Canvas 2D, and DOM.

## Apply a theme

<Code code={sample} lang='ts' title='theme.ts' />

`TerminalTheme` includes the named UI colors (`background`, `foreground`, `cursor`, `selectionBackground`, `selectionForeground`, optional `cursorText`), `minimumContrast`, and a `palette` array of **256** RGB entries.

<Aside type='caution' title='Pitfall: partial theme objects'>
  `setTheme()` validates that `palette` has length 256 with integer `0..255` RGB channels. Spread
  `terminal.appearance.theme` (and clone `terminal.appearance.theme.palette` if editing individual
  ANSI indices) so you never drop required entries.
</Aside>

Set `minimumContrast` above `1` to enforce a minimum WCAG contrast ratio between a cell's resolved foreground and background colors (default `1` leaves colors untouched).

## Batch appearance updates

When several visual properties change together (for example, switching between a dark and light app theme), call `terminal.setAppearance({ theme, font, cursor, backgroundOpacity, colorScheme })`. That commits one atomic revision and triggers a single repaint instead of repainting once per setter. On `ghostty-webgpu/worker`, all appearance setters return promises.

## Background opacity and backdrops

The root `.ghostty-webgpu` element paints the default theme background across the entire container (including padding and remainder pixels outside the cell grid), while renderers leave default-background cells transparent.

- Set `backgroundOpacity` in `[0, 1]` (default `1`, matching Ghostty's `background-opacity`) to fade that root fill and let a page backdrop show through.
- Set `backgroundOpacity: 0` if your page paints its own surface behind the terminal.
- Cells with an explicit SGR background color stay opaque so TUI panels and status bars remain readable.

## Resolve a host Ghostty config

`ghostty-webgpu/config-resolver` runs in Node or Bun and invokes a native helper binary on macOS (`darwin-arm64`, `darwin-x64`) and Linux (`linux-arm64`, `linux-x64`) to parse a user's Ghostty config file into a structured appearance object (including `surface.backgroundOpacity` and light/dark profiles).

Keep `ghostty-webgpu/config-resolver` strictly on the server and send only the resolved appearance JSON to the browser client.
