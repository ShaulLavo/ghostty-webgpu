## 2. Use the Ghostty keymap

| Action                      | macOS                      | Linux and Windows              |
| --------------------------- | -------------------------- | ------------------------------ |
| Copy                        | Cmd+C                      | Ctrl+Shift+C                   |
| Select all                  | Cmd+A                      | Ctrl+Shift+A                   |
| Clear above the prompt      | Cmd+K                      | Ctrl+Shift+K                   |
| Increase font size          | Cmd+=                      | Ctrl+=                         |
| Decrease font size          | Cmd+-                      | Ctrl+-                         |
| Reset font size             | Cmd+0                      | Ctrl+0                         |
| Top or bottom of scrollback | Cmd+Home or Cmd+End        | Shift+Home or Shift+End        |
| Scroll one page             | Cmd+PageUp or Cmd+PageDown | Shift+PageUp or Shift+PageDown |

On Mac, Cmd+Left and Cmd+Right move to the start and end of the shell line. Cmd+Backspace kills the line. Option+Left and Option+Right move by word. These shortcuts send text actions directly to the shell. The shell must support them. Option+letters still compose characters.

Clear removes the selection, scrollback, and rows above the cursor while keeping the prompt row at the top. It does nothing on the alternate screen. Copy declines an empty selection.

Paste uses the browser's paste event, including bracketed paste when the application enables it. No default binding reads the clipboard or requests clipboard-read permission.

## 3. Customize the map

`bindings` appends to `ghosttyKeymap[platform]`. User bindings override defaults. Pass `keymap: []` to replace the defaults entirely. Pass `screenReaderMode: () => enabled` to disable the five Mac text shortcuts during screen-reader use. Session-based hosts should share that predicate with core's `inputHooks.screenReaderMode`.

## 4. Share a host keymap

A host with `@fregat/hotkeys` can pass `mode: 'hosted'`, its dispatcher, the parent focus node, and platform. The host owns the bindings and matcher. Import `ghosttyKeymap` and `terminalShellKeysPack` from `ghostty-webgpu/hotkeys` for binding data. The [hotkeys integration note](https://github.com/ShaulLavo/ghostty-webgpu/blob/main/docs/hotkeys.md) covers the focus adapter and commands.

## If it doesn't work

### Clipboard access fails

Copy needs a secure context and a user gesture. Provide `clipboard: { readText, writeText }` and `onError` for a different clipboard policy. Hosts that can read silently may bind `terminal.paste` explicitly.

### Worker attachment reports a capability error

This adapter needs immediate native input-mode authority. Use the main-thread terminal. Worker terminals use native VT encoding without the add-on.
