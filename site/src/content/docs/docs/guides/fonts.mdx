`ghostty-webgpu` derives one integer device-pixel cell grid from your font metrics and uses it across layout, pointer projection, selection, and every renderer. That keeps columns sharp and aligned across Retina displays and fractional zoom levels like `1.25x` or `1.5x`.

## Load web fonts before opening

<Code code={sample} lang='ts' title='fonts.ts' />

Await your `FontFace` (or `document.fonts.load('400 14px "Your Font"')` for CSS `@font-face` rules) before calling `open()`. When the face is already loaded, the synchronous initial fit measures your real font on frame one. If a font finishes loading after `open()`, the built-in `document.fonts` observer automatically re-measures the grid and clears the glyph atlas.

<Aside type='caution' title='Pitfall: mismatched family names or missing CORS'>
  If the terminal still renders in a fallback monospace font, check two things: the
  `appearance.font.family` string must match the registered `FontFace` family name verbatim, and
  cross-origin font files must send `Access-Control-Allow-Origin` headers so the canvas glyph
  rasterizer can draw them cleanly.
</Aside>

For `ghostty-webgpu/worker`, supply faces through the `fonts` creation option instead of `document.fonts` (see [Run in a worker](https://ghostty.shaulavo.dev/docs/guides/workers/)).

## Changing font metrics at runtime

Call `terminal.setFont(partial)` to update `family`, `size`, `lineHeight`, `letterSpacing`, `weight`, or `boldWeight` live.

- **`size`** is the CSS em size in pixels. Measured cell height comes from the font's ascent plus descent, so a 14 px font at `lineHeight: 1.2` produces a taller cell than 14 px. Inspect `terminal.appearance.grid.cellHeight` to see the exact fitted pixel height.
- **`lineHeight`** multiplies the natural font box (minimum `0.5`). Values below `1` center glyphs inside a shorter cell and clip them to their cell span.
- **`letterSpacing`** adjusts horizontal advance in CSS pixels; negative values work as long as the fitted device cell width stays positive.

## Unicode widths, ligatures, and BiDi

- **Cell widths and graphemes:** `libghostty-vt` owns whether a code point occupies 1 or 2 cells; browser font fallback only draws inside that span. When an application enables DEC mode 2027 (grapheme clustering), ZWJ sequences such as `👩‍💻` occupy 2 cells and stay intact even across byte-by-byte writes.
- **Programming ligatures:** Off by default. Pass `ligatures` to `Terminal.create()` to read the font's `GSUB` table and shape joined runs without changing underlying cell ownership.
- **Bidirectional text:** Off by default. Pass `bidi: true` to lazy-load Unicode 13.0 bidirectional row reordering (`bidi-js`) for right-to-left scripts.
