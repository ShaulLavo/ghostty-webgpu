An unofficial Ghostty for the web.

libghostty-vt compiled to WebAssembly, drawn by a damage-aware WebGPU renderer, behind an xterm-shaped API. Click the terminal and type.

npm install ghostty-webgpu

          Only what changed is drawn. The renderer tracks damage per cell, so an
          idle terminal costs nothing and a busy one costs only its busy rows.
