# Internal working notes

These files are working notes, not user documentation: measurement dumps, phase reports, acceptance records, a rejected experiment, and the autonomous-research workflow (`program.md`). The README and the public pages in `docs/` never link here. An item leaves when the owner decides it is not worth keeping, in which case it is deleted and git history keeps it, or when a public page or an ADR in `docs/adr/` takes over its conclusion.
