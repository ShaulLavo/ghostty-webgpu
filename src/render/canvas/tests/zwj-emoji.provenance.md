# Canvas ZWJ emoji fixture

`zwj-emoji.ttf` is a subset of Twemoji Mozilla 0.7.0. Its COLRv0 and CPAL tables
provide outline-based color glyphs for Safari and Chromium. The previous Noto
fixture contained CBDT and CBLC bitmap tables, which native iOS Safari rejected.

This derivative removes unused characters, glyphs, and tables with FontTools.
It does not change the artwork, advances, or font metrics. Attribution and the
license links remain with the fixture. Browser tests load the committed file
without network access or Python.

## Regenerate

Use Python with `fonttools==4.66.1`. Download the release asset above, then run
these commands from the repository root:

```sh
python3 scripts/subset-canvas-zwj-font.py /path/to/Twemoji.Mozilla.ttf
python3 scripts/subset-canvas-zwj-font.py /path/to/Twemoji.Mozilla.ttf --check
```

The generator rejects other source bytes or FontTools versions. It preserves the
source timestamps and layout closure, including the technologist and family ZWJ
ligatures and their COLRv0 layers. `--check` compares the generated bytes with the
committed file without writing. The subset is 17,632 bytes with SHA-256
`0351d72344b62795cfe1410e2166f396f3a69846d23c81de0c60b79d511cce56`.

## Coverage and oracle

The Unicode set is U+200D, U+1F466, U+1F467, U+1F468, U+1F469, U+1F4BB, and
U+1F600. It covers boy, girl, man, woman, laptop, and grinning face, plus the
`👩‍💻` and `👨‍👩‍👧‍👦` ligatures. FontTools also retains other ligatures reachable
from these characters. The text font and system fallback still provide ASCII,
combining marks, and CJK, as before.

The ten browser cases compare the renderer with a direct Canvas oracle in the
same browser. They are not cross-browser golden screenshots. Keep their fixed
cell geometry, pixel comparisons, style boundaries, selection checks, and row
damage checks unchanged. Font loading alone does not prove shaping or painting.
Run the complete file on Chromium and native Safari after changing this fixture.
